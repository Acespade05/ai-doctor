System design
Three layers, least privilege.
How an incident flows from raw telemetry to a verified recovery — and why it's safe.

👁 Watcher

Polls the patient agent every few seconds for host metrics and probes the public site. Flags anomalies against learned baselines and thresholds.

🩺 Doctor

Three-tier diagnosis: deterministic rules → RAG over past incidents → LLM reasoning. Each diagnosis carries a tier, root cause, action and confidence.

📣 Narrator

This dashboard. Engineer sees telemetry, Founder sees live business impact, Executive sees the reliability scorecard.

Security posture

least privilege is part of the design
Agent access
Whitelisted commands only

Agent runs only stop/start/restart on named containers. No arbitrary shell.

Isolation
Patient ↔ Doctor separated

Token on every call; port 8080 firewalled to the Doctor only.

Actions
Reversible by default

Risky cases escalate for human approval; auto-fix is capped per service.
