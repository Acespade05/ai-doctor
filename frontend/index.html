Architecture

How the Doctor works.

1 · Observe

Polls the patient agent's metrics API and probes the public site every 10s.

2 · Detect

Rules-first thresholds now; Isolation Forest anomaly scoring once the baseline matures.

3 · Diagnose

Rules → RAG (ChromaDB) → LLM (Groq). Tiers 2–3 pending.

4 · Act

Auto-restart safe, reversible actions; escalate the rest with a summary.

5 · Verify

Fresh probes confirm recovery before an incident is closed.
